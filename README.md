# AutoMC · 鸣潮自动

AutoMC 帮你安排官服鸣潮每日任务、调用 OK-WW、记录运行结果并发送通知。实际游戏操作由 OK-WW 完成。

## 下载哪个文件？

到 [官方下载页](https://github.com/940963818qieke-crypto/AutoMc-Releases/releases/latest)，下载 **`AutoMC-v版本号.zip`**，完整解压后打开顶层 **`AutoMC.exe`**。

不要下载 `Source code` 当作程序，也不需要单独找 Core 或 Manager 包。当前版本为 **AutoMC 1.5.1，内含 Manager 1.0.3**。

## 第一次使用：六步上手

1. 安装官服鸣潮和 OK-WW，确认游戏能登录、OK-WW 能识别游戏。
2. 解压 AutoMC 到固定目录，打开 `AutoMC.exe` → 点击“启动 AutoMC”。
3. 到“基础配置”，选择鸣潮和 OK-WW 安装目录并保存。
4. 到“每日任务”，选择单账号或多账号，设置刷本和附加任务并保存。
5. 按需设置“通知”；检查任务结束后的关闭游戏、自动关机选项。
6. 手动运行确认符合预期后，再设置时间并点击“开启每日自动运行”。

自动任务需要电脑开机且处于已登录、可交互的桌面；不要期待它在关机或锁屏状态下操作游戏。

## 怎么选任务？

- **单账号**：执行当前登录账号，不切换账号；不等于自动选择登录列表第一项。
- **多账号**：由 OK-WW 按原生逻辑切换并执行每日任务。
- **体力用途**：无音区、凝素领域或模拟领域。
- **附加任务**：每周乐园、梦魇巢穴、弃置声骸融合、4C 声骸。
- **4C 新配置默认 20 次**；用于每日附加任务时必须选择传送目标。

展开“任务参数设置”，先选默认配置或某个账号，再为需要修改的参数选择“单独设置此项”。开关可直接选“沿用 / 开启 / 关闭”；沿用会显示来源和值，不等于关闭。底部“保存所有设置”始终可见，保存整页内容。

## 配置保存在哪里？

**分账号设置 > AutoMC 默认设置 > OK-WW 原配置**。

导入 OK-WW 配置会先预览，确认后只填入当前编辑范围，点击保存才生效。导入默认设置不会抹掉其他账号的单独覆盖；跟随默认的账号会使用新默认值。

所有编辑保存在 AutoMC，运行时临时传递参数，不改写 OK-WW 原始配置文件。两边不会自动双向同步。

## 更新与故障

- 通过 Manager 更新即可；Manager 和 Core 版本号不同是正常的。
- 离线仍可启动已安装 Core；版本查询失败不代表每日任务不能运行。
- 移动目录后，重新安装计划任务。换电脑可导出 / 导入配置，再调整路径和通知授权。
- 用户数据位于 `%LOCALAPPDATA%\AutoMC`。
- 反馈错误请提供时间、AutoMC / OK-WW 版本及最新结果，不要发送令牌、兑换码或管理密钥。

详细步骤见 [使用说明](使用说明.md)。新增选项未代替真实游戏环境验证；是否“已验证”以对应版本兼容记录为准。

### 每日任务页操作说明

按顺序选择账号模式、运行时间、结束行为。任务参数按需展开，底部“保存所有设置”统一保存整页（包括折叠参数）。有未保存修改时会提示。

“开启每日自动运行”会先保存，再创建 Windows 计划任务；已经开启时显示“保存并更新自动运行”。“取消每日自动运行”只移除计划任务，不删除账号或参数。

凝素领域仍按游戏 F2 序号定位。旁边按迅刀、音感仪、长刃、臂铠、配枪每五项循环提示类型和组别；这是排列参考，不保证未来版本或新旧材料顺序，具体以游戏列表为准。模拟领域直接选择角色经验、武器经验或贝币。
